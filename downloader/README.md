# محمّل ملفات ديسكورد — خلفية شفافة 🎬

برنامج بنافذة رسومية: تحط الرابط، تختار الصيغة، وينزّل لك الملف ويحوّله بخلفية شفافة تلقائياً.

يفهم تلقائياً نوع الملف من الرابط:
- **APNG متحرك** (روابط `/animated` و `/assets/content/...`)
- **WebM فيديو** (روابط `/video`)
- **صور PNG ثابتة**

## الصيغ المدعومة

| الصيغة | الاستخدام |
|--------|-----------|
| **MOV — ProRes 4444** | للمونتاج (Premiere / After Effects)، أعلى جودة + شفافية |
| **MOV — QuickTime Animation** | شفاف وأخف حجماً |
| **WebM شفاف** | للويب وديسكورد |
| **GIF شفاف** | توافق واسع |
| **PNG / الأصلي** | صورة ثابتة أو تنزيل الملف كما هو |

## التشغيل على ويندوز (الأسهل)

1. ثبّت **بايثون** من <https://www.python.org/downloads/> — وأثناء التثبيت اختر **"Add Python to PATH"**.
2. انقر مرتين على ملف **`تشغيل.bat`**.
   - أول مرة يثبّت المكتبات تلقائياً (يحتاج إنترنت، دقيقة تقريباً).
   - بعدها تفتح النافذة.
3. الصق الرابط، اختر الصيغة، اختر مجلد الحفظ، واضغط **تحميل وتحويل**.

> ffmpeg مدمج تلقائياً عبر مكتبة `imageio-ffmpeg` — ما تحتاج تثبّته يدوياً.

## التشغيل اليدوي (أي نظام)

```bash
pip install -r requirements.txt
python discord_downloader.py
```

## ملاحظات

- شفافية MOV/WebM تظهر صح في برامج المونتاج والمتصفحات الحديثة. بعض المشغّلات البسيطة (مثل Windows Media Player) تعرض خلفية سوداء — هذا طبيعي ومو خطأ في الملف.
- لو الرابط صورة ثابتة واخترت صيغة فيديو، يحفظها PNG شفاف تلقائياً.
